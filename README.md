# CCW MCQ Practice

A simple MCQ practice and mock-test website built with Next.js App Router, TypeScript, and Tailwind CSS.

## Features

- Subject-wise practice with randomized sessions
- Mock test with 50 questions (10 per subject) and 1-hour timer
- Dark, responsive UI
- Local-only state (no backend)

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.
##Script
```bash
npm run dev
npm run lint
npm run build
npm run start
```
